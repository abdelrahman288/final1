# Abdou-Luncher — الشرح بالبساطة

## 1) الرفع على GitHub (بنفس الطريقة اللي نجحت قبل كده)
فك الضغط، وارفع **كل محتويات الفولدر** (بما فيها `.github` و `app` و `gradle`) على الريبو القديم واستبدل الملفات. استنى البناء (Actions) ينتهي وحمّل `Abdou-Luncher.apk` من Artifacts وثبّته فوق القديم.

## 2) صوت البسملة بصوت مشاري
الـ workflow بيحاول ينزّلها لوحده. لو الـ APK اتبنى من غير صوت: حط ملف صوت اسمه `bismillah.mp3` جوه `app/src/main/assets/` وارفعه، أو انسخه على الفلاشة في `Abdou-Luncher/bismillah.mp3`.
الصوت بيشتغل **فقط** لما الشاشة تفتح وتظهر اللانشر. أي فتح تاني = بدون صوت.

## 3) تفعيل خدمة الحماية (مهمة للـ Home وإطفاء الشاشة الحقيقي)
الأسهل: من الكمبيوتر بـ ADB (مرة واحدة):
```
adb connect IP_التلفزيون
adb shell pm grant com.noor.launcher android.permission.WRITE_SECURE_SETTINGS
adb shell appops set com.noor.launcher SYSTEM_ALERT_WINDOW allow
adb shell dumpsys deviceidle whitelist +com.noor.launcher
```
بعدها افتح اللانشر ← الإعدادات ← «خدمة الحماية» وهتتفعّل. (أو فعّلها يدوي من إعدادات التلفزيون ← إمكانية الوصول لو القائمة موجودة.)
**الأمان:** الخدمة لا تقرأ محتوى الشاشة ولا تتصل بالإنترنت. ضغطتين سريعتين على Home = الواجهة الرسمية (مخرج طوارئ). لإلغائها: إعدادات ← إمكانية الوصول ← إيقاف، أو `adb shell settings put secure enabled_accessibility_services ""`.

## 4) المواقيت والساعة بدون إنترنت
- المواقيت بتتحسب جوه التطبيق (سوهاج افتراضي، والتبديل من «مواقيت اليوم»).
- التوقيت الصيفي المصري مبرمج داخلياً.
- الساعة من ساعة التلفزيون. لو بعد فصل الكهرباء ظهرت علامة تحذير، اضغطها واضبط التاريخ/الوقت يدوي. لا يوجد جهاز يعرف الوقت بدقة بدون أي مصدر، فالضبط اليدوي مرة واحدة هو الحل.
- فيه ضبط دقائق لكل صلاة لو حابب تطابق مسجدك.

## 5) مشغّل القرآن
من الرئيسية: اختر فولدر الملفات (اسمح بالوصول للملفات)، وفيه تتابع / تكرار الكل / تكرار واحدة، وضغط مطوّل على ملف لتحديد أكتر من ملف. زر «إطفاء الشاشة» يطفّي الشاشة فعلياً والصوت يكمل، وزر OK بالريموت يصحّيها.

## 6) التطبيق التلقائي
الإعدادات ← «تطبيق يفتح عند تشغيل الشاشة» (مثلاً تطبيق القنوات).

## تنبيه
ميزات Home والإطفاء الحقيقي والتشغيل التلقائي تعتمد على سلوك نظام التلفزيون وماتجرّبتش على جهازك، لو حاجة منها ماشتغلتش قولّي وأضبطها.
